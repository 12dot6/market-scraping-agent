Formulation Wiki Prototype App

This is a minimal Vite + React + Tailwind scaffold that implements Shadcn-style components using Tailwind utilities.

Quick start

1. Change to the app folder:

```bash
cd _bmad-output/prototype-app
```

2. Install dependencies and run dev server:

```bash
npm install
npm run dev
```

Open http://localhost:5173 in your browser.

Notes
- This scaffold implements lightweight components (Button, UrlInputPanel, ProgressBoard) using Tailwind.
- For full production parity with a true `shadcn/ui` workflow, integrate the official shadcn component set and design tokens; that requires additional setup.
